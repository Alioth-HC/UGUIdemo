# Unity UGUI 综合练习项目

基于 Unity 开发的游戏 UI 综合练习项目，围绕游戏常见界面进行设计与实现，涵盖界面布局、数据展示、动态列表生成及交互逻辑等内容。

## 核心功能

- **主界面（HomePanel）**：实现玩家基础信息与金币等数据的展示与使用消耗。
- **背包系统（InventoryPanel）**：实现物品界面布局与背包内容展示。
- **任务系统（TaskPanel）**：实现任务列表动态生成、任务详情展示、任务状态管理及奖励领取。
- **动态 UI 交互**：通过 Button、TMP_Text、Scroll View 等组件实现界面交互与内容展示。
- **数据管理**：使用 C# 类封装任务数据，实现 UI 与数据逻辑的分离。
- **界面组织**：通过多个独立 Panel 组织游戏 UI，便于功能扩展与维护。

## 技术栈

Unity、C#、UGUI、TextMeshPro、面向对象设计、动态 UI 生成、事件监听

## 项目目的

通过实际开发熟悉 Unity UGUI 的常用组件与交互机制，掌握游戏界面的基本组织方式、数据驱动 UI 的实现思路，为后续游戏客户端开发打下基础。
